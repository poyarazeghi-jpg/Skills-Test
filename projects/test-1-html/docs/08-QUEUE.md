# QUEUE — صف کارهای دسته‌ای
> طبق `batch-task-queue`: ثبت خام، اولویت‌بندی، اجرا با WIP=1. هر آیتم **یک commit و یک push**.

## معیار اولویت‌بندی
باگ مسدودکننده/داده‌خراب‌کن (صرف‌نظر از اندازه) > وابستگی‌ها (A قبل از B) > ارزش بالا/تلاش کم > بقیه
