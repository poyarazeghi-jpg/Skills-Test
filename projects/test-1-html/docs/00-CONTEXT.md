# CONTEXT — خلاصه‌ی پروژه (حداکثر ۴۰ خط، هر فاز دوباره نوشته شود)

## هدف
«کلیکو»: صفحه‌ی وب ایستای فارسی که «سلام دنیا» نشان می‌دهد؛ دکمه‌ی «کلیک کن» پیامی ساده نشان می‌دهد و باکس «درباره من» زیر دکمه است. تست ۱ ریپوی Skills-Test.

## Stack
HTML/CSS/JS ساده بدون build؛ طراحی با taste-skill (فقط فایل‌های استفاده‌شده‌ی کیت در assets/)؛ سطح ماژولار: سبک.

## ساختار (یک سطح)
- index.html — صفحه (هیرو centred، باکس درباره من در قاب هیرو، فوتر close-word)
- config/app.js — تنها منبع هویت برنامه؛ scripts/main.js — پر کردن هویت و پیام کلیک
- styles/page.css — استایل صفحه (پنجره‌ی درباره من، حاشیه‌ی RTL سربرگ)
- assets/ — کیت taste-skill دست‌نخورده؛ docs/ — مستندات؛ .taste-skill/waivers.json — معافیت‌های gate

## قانون‌های این پروژه (حداکثر ۵ تا)
- اسم برنامه فقط در config/app.js تایپ می‌شود؛ متن صفحه فقط در index.html؛ JS رشته‌ی رو‌به‌کاربر ندارد.
- فایل‌های کیت (assets/) دست‌نخورده می‌مانند؛ FAIL با معافیت و دلیل رفع می‌شود، نه با دست‌کاری کیت.
- صفحه را از راه http باز کن (مثلاً python3 -m http.server)؛ اسکریپت‌های کیت روی file:// کار نمی‌کنند، کلیک دکمه کار می‌کند.
