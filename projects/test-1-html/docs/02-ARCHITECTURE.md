## 🧱 Stack فنی

| لایه | تکنولوژی | دلیل انتخاب |
|------|-----------|-------------|
| Runtime/Platform | مرورگر؛ HTML، CSS و JavaScript ساده بدون build | سایت ایستا؛ پلتفرم خودش پشته است و سرور لازم نیست |
| طراحی | taste-skill (`design-taste-frontend`)؛ فقط بخش‌های استفاده‌شده‌ی کیت | انتخاب کاربر در kickoff؛ بررسی نهایی با gate در Chrome |
| سطح ماژولار | **سبک**: متن‌ها یک‌جا (`index.html`)، کانفیگ جدا (`config/app.js`)، استایل جدا (`assets/` و `styles/`) | صفحه‌ی ایستا با منطق تقریباً صفر؛ انتخاب کاربر |
| پایگاه‌داده و ذخیره‌سازی | ندارد | داده‌ای نگهداری نمی‌شود |

## ⚙️ پیکربندی محیط (Config Reference)

متغیر محیطی یا secret ندارد. هویت برنامه (نام، سازنده، برند، کمپانی) فقط در `config/app.js` می‌آید و بقیه‌ی محصول از همان می‌خوانند.

---

## ⚠️ نکات فنی خاص این پلتفرم/زبان

- اسکریپت‌های خود پروژه (`config/app.js`، `scripts/main.js`) کلاسیک‌اند تا با `file://` هم کار کنند؛ اسکریپت‌های کیت ماژول ES‌اند و فقط از راه http کار می‌کنند (مثلاً `python3 -m http.server`)؛ ورود هیرو و واکنش hover فقط همان‌جا فعال است.
- gate و اسکرین‌شات‌های taste-skill به Chrome نیاز دارند؛ در محیط چت یک Chromium از npm بیرون از ریپو با متغیر `CHROME_PATH` به‌کار می‌رود.
- push در محیط چت: کش credential بین دو اجرای ابزار زنده نمی‌ماند؛ احراز هویت (`git_auth.sh`) و push باید در همان اجرا انجام شوند.
