# 🏗️ ARCHITECTURE — معماری فنی
**نسخه:** 1.0.0 | **تاریخ ایجاد:** 2026-11-15 | **آخرین آپدیت:** 2026-11-15

> این فایل «چطور ساخته شده» است. اگر یک تصمیم فنی عوض شد (کتابخانه، ساختار پوشه، الگوی داده)، همین فایل باید همان لحظه آپدیت شود.

---

## 🧱 Stack فنی

| لایه | تکنولوژی | دلیل انتخاب |
|------|-----------|-------------|
| Runtime/Platform | مرورگر؛ HTML، CSS و JavaScript ساده بدون build | سایت ایستا؛ پلتفرم خودش پشته است و سرور لازم نیست |
| طراحی | taste-skill (`design-taste-frontend`)؛ فقط بخش‌های استفاده‌شده‌ی کیت | انتخاب کاربر در kickoff؛ بررسی نهایی با gate در Chrome |
| سطح ماژولار | **سبک**: متن‌ها یک‌جا (`index.html`)، کانفیگ جدا (`config/app.js`)، استایل جدا (`assets/` و `styles/`) | صفحه‌ی ایستا با منطق تقریباً صفر؛ انتخاب کاربر |
| پایگاه‌داده و ذخیره‌سازی | ندارد | داده‌ای نگهداری نمی‌شود |
